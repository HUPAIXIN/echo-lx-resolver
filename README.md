# LX 音源解析 (echo.lx-resolver)

为 **ECHO**(Steam 版,配合 [ShinawaseLoader](https://github.com/ChunchunOwO/ShinawaseLoader) 使用)添加流媒体**解析源切换**:在流媒体页的音质选择旁多出一个下拉,可在 本地公共解析 / 账号解析 / 自定义洛雪(LX Music)音源 之间自由切换。

> ⚠️ **前置要求**:需要已安装 [ShinawaseLoader](https://github.com/ChunchunOwO/ShinawaseLoader) 并**启用 ECHO Streaming** 模块。洛雪音源脚本需要自备(本仓库不提供任何音源)。

## 功能

- **解析源切换**:本地(公共解析,无需登录)/ 账号(使用已登录账号的权限)/ 自定义洛雪音源,一键切换,立即生效
- **自定义洛雪音源**:支持从 URL 直链或本地 JS / JSON / TXT 文件添加**多个**洛雪音源
- **音源管理**:右键音源可 更新(主动触发音源自检)/ 编辑(改名、换 URL、换文件)/ 删除;有新版本时按钮右上角与音源名称左侧会显示红点
- **音质自动降级**:所选音质不可用时按 Hi-Res → 无损 → 320k → 128k 自动降级重试
- **平台映射**:网易云 → `wy`、QQ 音乐 → `tx`(酷我 / 酷狗 / 咪咕等按音源声明自动支持)
- **隐私与安全**:播放流经本机(127.0.0.1)中转,隔离浏览器 Cookie 污染,不上传任何数据

## 安装

1. 前往 [Releases](https://github.com/HUPAIXIN/echo-lx-resolver/releases) 下载最新的 `LX-音源解析.echomod`
2. 打开 ECHO → 侧栏 **Shinawase Loader → Mods → 导入**,选择下载的 `.echomod` 文件(或直接把 `.echomod` 拖入 Mods 页)
3. 确保 **ECHO Streaming** 模块处于启用状态
4. 进入流媒体页,音质选择旁会出现"解析音源"下拉

## 使用

1. 点击"解析音源"下拉 → **＋ 添加音源…**
2. 粘贴洛雪音源脚本直链 URL,或选择本地 `.js` / `.json` / `.txt` 音源文件
3. 在列表中选择该音源即可启用;**右键**音源可 更新 / 编辑 / 删除
4. "本地"使用无需登录;"账号"模式需要先在账号页登录对应平台

### 音质映射

| ECHO 音质 | 洛雪音质 |
|---|---|
| 标准 | 128k |
| 高音质 | 320k |
| 无损 | flac |
| Hi-Res | hires |

所选音质在音源不可用时按上表反向自动降级。

## 常见问题

- **提示"音源未能提供这首歌曲的播放地址"**:音源服务端确实没有这首歌曲的地址(版权/权限限制),可尝试其他音源或稍后再试
- **提示"无法连接音源的更新服务器"**:音源作者的服务器暂时不可用,稍后再试
- **QQ 音乐在"本地"模式下不可用**:QQ 音乐没有公共(免登录)接口,本地模式仅支持网易云音乐
